# 数据定义

票号与原始编号均为字符串，保留前导零。称重支持 kg、公斤与 t，统一为 kg，单价为 CNY/kg。
毛重与皮重按票号和版本配对，品类、单价、扣杂率与更正目标必须一致。计价重量=(毛重−皮重)×(1−扣杂率)，先量化到0.001kg，再乘单价，金额四舍五入到0.01CNY。
每票第一版不填写 replaces。后续版本只能替代当前生效版，分支或缺基版整票阻断结算。已支付额为各版本中最大累计已付值，待付=最终应付−累计已付；负待付表示待收回。
同编号同原值仅计一次；同编号不同原值全部隔离。空文件、全空行和仅表头分别报错。原始输入计数包括空行及重复表头，对账会分别解释。
归档封存保存逐版证据、隔离原因和运行摘要，非支付执行系统。数据使用虚构编号，不连接实际支付渠道。

拼车货包：id 与 ticket 为字符串，保留前导零；household 为户名；baskets 为非负整数筐数；est_kg 为估重 kg；price 为成交单价 CNY/kg；flag 取 正常/补筐/退运（兼容 normal/supplement/returned）。
缺估重、归属冲突（同编号不同原值）、整筐退运、票号未生效的货包不进入可发布金额，但作为排除证据随批次保存。
户暂计金额=Σ(货包估重×成交单价)，逐货包四舍五入到 0.01CNY 后求和。分摊差额=车票应付−暂计合计，按暂计金额比例量化分摊，尾差落给份额最大的户并单独标记。每户可发布金额=暂计+分摊+尾差；同票户级合计必须等于车票应付，否则该票禁止发布。
发布记录按票号版本化保存：run_id、规则版本、应付、逐户金额、排除货包引用、内容摘要、发布时间，以及相对上一版的逐户影响（impact）。内容摘要一致重复发布不新增版本。
